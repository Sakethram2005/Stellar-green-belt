# 🔒 Stellar Escrow Pay

> Trustless escrow payments for freelancers and small businesses, built on Stellar Soroban.

**Level 4 — Green Belt · Soroban Scout Program**

## 🌐 Live Demo
**[stellar-escrow-pay.vercel.app](https://stellar-escrow-pay.vercel.app)**

## 📋 What It Does

A client locks XLM in a Soroban smart contract. The freelancer completes work. The client approves and funds release instantly. No middlemen, no delays, no disputes.

**Flow:** Create → Fund → Approve → Release

## 🔄 Improvement Summary

**1. Dispute Resolution System**
Requested by U07. Added `raise_dispute()` function to the Soroban contract and a ⚖️ Dispute button on funded escrow cards, so either party can flag an issue.
Commit: [87bde88](https://github.com/Sakethram2005/Stellar-green-belt/commit/87bde88)

**2. Deadline-Based Escrow**
Requested by U06. Added a `deadline` parameter to `create_escrow()`. If the client is unresponsive, the freelancer can call `claim_after_deadline()` to release funds automatically.
Commit: [4df98c3](https://github.com/Sakethram2005/Stellar-green-belt/commit/4df98c3)

**3. Improved Status & Role Display**
Requested by U05. Added color-coded status badges (Active/Funded/Completed/Disputed) and "You: Client" / "You: Freelancer" role badges so users instantly understand their position in each escrow.
Commit: [83add0f](https://github.com/Sakethram2005/Stellar-green-belt/commit/83add0f)

**4. Transaction Status Notifications**
Requested by U02. Added live toast notifications for every action (creating, funding, approving, cancelling) with clickable Stellar Explorer links.
Commit: [bd6351a](https://github.com/Sakethram2005/Stellar-green-belt/commit/bd6351a)

**5. Onboarding Guide**
Requested by U09. Added a "How it works" walkthrough directly inside the Create Escrow form so first-time users understand the full flow before creating one.
Commit: [a400766](https://github.com/Sakethram2005/Stellar-green-belt/commit/a400766)

## ⚙️ Setup & Run Locally

### Prerequisites
- Node.js 20+
- Rust + `wasm32-unknown-unknown` target
- Freighter browser extension (testnet mode)

### 1. Clone
```bash
git clone https://github.com/Sakethram2005/Stellar-green-belt.git
cd Stellar-green-belt
```

### 2. Run contract tests
```bash
cd contracts/escrow
cargo test --features testutils
```

### 3. Configure environment
```bash
cp .env.example .env
```

### 4. Run frontend
```bash
npm install
npm run dev
```

### 5. Fund testnet wallet
```
https://friendbot.stellar.org?addr=YOUR_WALLET_ADDRESS
```
